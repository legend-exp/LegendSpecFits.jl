LegendSpecFits.LegendSpecFits — Module
LegendSpecFits

Fitting routines for the analysis of germanium detector spectra in the LEGEND experiment.

The package provides gamma peak shapes and binned Poisson likelihood fits for energy calibration and resolution curves, charge-trapping correction, A/E and LQ pulse shape discrimination, SiPM calibration, filter parameter optimization, and goodness-of-fit tests. Most fit functions return a tuple (result, report) of the fit results and the data needed to plot them with LegendMakie.lplot.

BinnedPoissonProcess(intensity::AbstractMeasure, edges::AbstractVector{<:Real}) <: MeasureBase.AbstractMeasure

Binned view of a Poisson point process with the given intensity measure: its variates are vectors of non-negative integer bin counts for the given bin edges (logdensityof assumes valid counts, binned_poisson_likelihood validates them). The count in each bin is Poisson-distributed, with the intensity mass in the bin as expectation, computed via analytic MeasureBase.smf differences where available (all spectral shapes, distributed over weighted measures and superpositions) and via Simpson's rule otherwise. Distribution intensities are converted to measures automatically.

LegendSpecFits.autocal_energy — Method
autocal_energy(
    e::AbstractArray{<:Real}, photon_lines::Vector{<:Unitful.Energy{<:Real}};
    mode::Symbol = :fit, min_e::Real = 100, max_e::Real = maximum(e),
    max_e_binning_quantile::Real = 0.5, σ::Real = 2.0, threshold::Real = 50.0,
    min_n_peaks::Int = length(photon_lines), max_n_peaks::Int = 4 * length(photon_lines),
    α::Real = 0.01, rtol::Real = 5e-3
)

Determines a linear energy calibration constant from uncalibrated energies e by matching peaks in the spectrum to the known photon energies photon_lines.

The uncalibrated spectrum is histogrammed with the Freedman-Diaconis bin width of the values between min_e and the max_e_binning_quantile quantile of e. The peak matching is done by RadiationSpectra.calibrate_spectrum (mode = :fit) or RadiationSpectra.determine_calibration_constant_through_peak_ratios (mode = :ratio).

Keywords

  • mode::Symbol = :fit: Matching method, :fit or :ratio. Other values throw an ArgumentError.
  • min_e::Real = 100: Lower end of the histogrammed range (uncalibrated units).
  • max_e::Real = maximum(e): Upper end of the histogrammed range.
  • max_e_binning_quantile::Real = 0.5: Quantile of e that limits the data used to choose the bin width.
  • σ::Real = 2.0, threshold::Real = 50.0: Expected peak width (in bins) and detection threshold of the peak finder.
  • min_n_peaks::Int, max_n_peaks::Int: Minimum and maximum number of peaks to search for.
  • α::Real = 0.01, rtol::Real = 5e-3: Significance level and relative tolerance of the peak matching.

Returns

A tuple (result, report) in which both are the same NamedTuple with the fields

  • f_calib: function that multiplies uncalibrated values by the calibration constant, giving values in keV.
  • h_cal: histogram of the calibrated energies from 0 to 3000 keV in 0.5 keV bins.
  • h_uncal: histogram of the uncalibrated energies.
  • c: calibration constant in keV per uncalibrated unit.
  • peak_positions: positions of the identified peaks in uncalibrated units.
  • threshold: peak finder threshold that was used.

LegendSpecFits.background_peakshape — Method
background_peakshape(
    x::Real, μ::Real, σ::Real,
    step_amplitude::Real, background::Real;
    background_slope::Real = 0.0, background_exp = 0.0, background_center::Real = μ
)

Evaluates the background part of a gamma peak at x:

\[A\,\mathrm{S}(x; \mu, \sigma) + b\,e^{-d\,(x - x_c)} + s\,(x - x_c)\,,\]

where $A$ is step_amplitude, $b$ is background, $d$ is background_exp, $s$ is background_slope and $x_c$ is background_center. The step $\mathrm{S}$ is a Gaussian-smoothed step with width σ that falls from 1 to 0 across μ with increasing x (more background below the peak). With the default keywords the exponential term reduces to the constant background.

LegendSpecFits.binned_poisson_likelihood — Method
binned_poisson_likelihood(model, h::Histogram{<:Real,1})

Constructs the binned Poisson likelihood of the observed histogram h, i.e. the likelihood of BinnedPoissonProcess(model(p), h.edges) given the bin counts h.weights. model is a Markov kernel that maps parameters to an intensity measure (e.g. a @pf property function combining shape measures, see GaussPeak).

A fixed intensity measure instead of model yields a parameter-independent likelihood.

The bin counts of h must be non-negative integers: a weighted histogram is not Poisson-distributed data and requires a different statistical treatment.

LegendSpecFits.chi2fit — Method
chi2fit(f_fit::Function, x, y; pull_t, v_init, lower_bound, upper_bound, pseudo_prior, uncertainty, correlated)
chi2fit(f_fit, x, y, yerr; kwargs...)
chi2fit(f_fit, x, y, yerr, xerr; kwargs...)
chi2fit(n_poly::Int, x, y; kwargs...)
chi2fit(f_outer::Function, n_poly::Int, x, y; kwargs...)

Fits the model f_fit to the data (x, y) by minimizing a chi-squared function with the Minuit minimizer (migrad).

x and y are vectors of numbers or Measurements. The uncertainty of each x is propagated through the model with forward-mode automatic differentiation and added in quadrature to the uncertainty of y. If all uncertainties are zero, all points have equal weight. Separate yerr (and xerr) vectors are converted to Measurements.

Arguments

  • f_fit: Model function f(x, p1, p2, ...). The number of fit parameters is first(methods(f_fit)).nargs - 2, so f_fit needs a single method with explicit parameter arguments.
  • n_poly::Int: Fits a polynomial of degree n_poly instead, with parameters ordered from the constant term upward (see PolCalFunc). With f_outer, the model is f_outer(poly(x)).

Keywords

  • pull_t::Vector{<:NamedTuple}: One entry per parameter. A NamedTuple (mean, std) adds a Gaussian pull term ((p - mean) / std)^2 to the chi-squared function; an empty NamedTuple() adds none. The default adds no pull terms.
  • v_init::Vector{<:Real}: Initial parameter values. Default is one for every parameter.
  • lower_bound::Vector{<:Real}, upper_bound::Vector{<:Real}: Parameter limits. Default is no limit.
  • pseudo_prior::Union{ContinuousMultivariateDistribution, Nothing} = nothing: If given, the minimization runs in a transformed space where one unit is one prior standard deviation, which keeps parameters in the support of the prior.
  • uncertainty::Bool = true: Calculate parameter uncertainties and goodness of fit from the Hessian of the chi-squared function.
  • correlated::Bool = true: If true, the returned parameters carry their full covariance, so that uncertainties of derived quantities, including report.f_fit, account for the parameter correlations. If false, the parameters are independent Measurements with the same marginal uncertainties, which overestimates the uncertainty of derived quantities when the parameters are correlated.

Returns

A tuple (result, report). result is a NamedTuple with the fields

  • par: best-fit parameters as Measurements. The uncertainty is NaN if uncertainty is false or the fit did not converge.
  • converged: whether the minimizer converged. A warning is issued if not.
  • gof: goodness of fit, only present if the uncertainties were calculated, as a NamedTuple with converged, pvalue, chi2min, dof, covmat and residuals_norm. The number of degrees of freedom counts each pull term as one data point; pvalue is NaN if it is zero.

report contains par, f_fit (the fitted model as a function of x), x, y and gof, for plotting with LegendMakie.lplot.

LegendSpecFits.ctc_aoe — Function
ctc_aoe(
    aoe_all::Vector{<:Real}, ecal_all::Vector{<:Unitful.RealOrRealQuantity},
    qdrift_e_all::Vector{<:Real}, compton_bands::Vector{<:Unitful.RealOrRealQuantity},
    peak::Real = 0.0, window::Tuple{<:Real, <:Real} = (50.0, 8.0),
    hist_start::Real = -20.0, hist_end::Real = 5.0, bin_width::Real = 0.05;
    aoe_expression = "aoe", qdrift_expression = "qdrift / e",
    pseudo_prior::NamedTupleDist = NamedTupleDist(empty = true),
    pseudo_prior_all::NamedTupleDist = NamedTupleDist(empty = true),
    fit_func::Symbol = :aoe_two_bck, pol_order::Int = 1
)

Corrects the drift time dependence of the A/E parameter.

Events in 20-wide energy bands starting at each value of compton_bands (in the unit of ecal_all) are selected, and those with A/E within window around peak are used. The corrected value is aoe + Σ_i fct[i] * qdrift_e^i for i = 1:pol_order. The coefficients fct minimize the Gaussian width of the A/E peak, found with a bounded derivative-free optimization (NLopt LN_BOBYQA) limited by the time limit of set_timelimit. The corrected A/E is finally shifted and scaled to mean 0 and standard deviation 1.

Arguments

  • aoe_all: A/E values of all events.
  • ecal_all: Calibrated energies of all events.
  • qdrift_e_all: Drift-time parameter divided by the energy of all events.
  • compton_bands: Lower edges of the energy bands that are used.
  • peak: Center of the A/E peak.
  • window: Widths (lower, upper) of the A/E range around peak that is used.
  • hist_start, hist_end, bin_width: Range and bin width of the A/E histograms.

Keywords

  • aoe_expression, qdrift_expression: Names of the A/E and drift-time variables in the returned func.
  • pseudo_prior: Replaces fields of the default prior of the A/E peak fits.
  • pseudo_prior_all: Accepted but not used.
  • fit_func::Symbol = :aoe_two_bck: Shape of the A/E peak fits (see fit_single_aoe_compton).
  • pol_order::Int = 1: Order of the polynomial in qdrift_e.

Returns

A tuple (result, report). result is a NamedTuple with the fields

  • peak, window: the input values.
  • func: the correction and normalization as a Julia expression string in aoe_expression and qdrift_expression.
  • fct: the coefficients of the correction.
  • σ_start, σ_optimal: the width of the half-truncated Gaussian fit without correction and with fct.
  • σ_before, σ_after, σ_after_norm: peak width from the fits before the correction, after it, and after the normalization.
  • before, after, after_norm: the corresponding fit results.
  • converged: whether the optimization converged.

report contains peak, window, fct, bin_width, bin_width_qdrift, the selected events (aoe_peak, aoe_ctc, aoe_ctc_norm, qdrift_peak), the histograms h_before, h_after, h_after_norm, the widths and the reports of the three fits, for plotting with LegendMakie.lplot.

LegendSpecFits.ctc_energy — Function
ctc_energy(
    e::Vector{<:Unitful.Energy{<:Real}}, qdrift::Vector{<:Real}, peak::Unitful.Energy{<:Real},
    window::Tuple{<:Unitful.Energy{<:Real}, <:Unitful.Energy{<:Real}},
    m_cal_simple::Unitful.Energy{<:Real} = 1.0u"keV";
    e_expression::Union{Symbol, String} = "e", pol_order::Int = 1
)

Corrects the dependence of the energy on the drift time (charge-trapping correction) in the peak at peak.

The events within window = (lower, upper) around peak are used. The corrected energy is e + Σ_i fct[i] * qdrift^i for i = 1:pol_order. The coefficients fct minimize the logarithm of the ratio of the FWHM to the height of the fitted peak, found with a bounded derivative-free optimization (NLopt LN_BOBYQA) limited by the time limit of set_timelimit. The peak is fitted with fit_single_peak_th228.

Arguments

  • e: Calibrated energies.
  • qdrift: Drift-time parameter of each event.
  • peak: Peak energy.
  • window: Widths (lower, upper) of the energy window around peak.
  • m_cal_simple: Simple calibration constant (energy per uncalibrated unit). fct in the result is divided by it, so that the correction func applies to the uncalibrated energy.

Keywords

  • e_expression: Name of the energy variable in the returned func.
  • pol_order::Int = 1: Order of the polynomial in qdrift.

Returns

A tuple (result, report). result is a NamedTuple with the fields

  • peak, window, m_cal_simple: the input values.
  • func: the correction as a Julia expression string, e_expression + fct[1] * qdrift^1 + ....
  • fct: the coefficients of the correction (divided by m_cal_simple).
  • fwhm_before, fwhm_after: FWHM of the peak before and after the correction, in keV.
  • converged: whether the optimization converged.

report contains peak, window, fct, bin_width, bin_width_qdrift, the selected events (e_peak, e_ctc, qdrift_peak), the histograms h_before and h_after, the FWHM values and the reports of both fits (report_before, report_after), for plotting with LegendMakie.lplot.

LegendSpecFits.cut_single_peak — Method
cut_single_peak(
    x::Vector{<:Unitful.RealOrRealQuantity}, min_x::T, max_x::T;
    n_bins::Int = -1, relative_cut::Float64 = 0.5, n_tries::Int = 5
) where T<:Unitful.RealOrRealQuantity

Determines a window around the single peak in the values x that lie strictly between min_x and max_x.

The values are histogrammed and the window is the range around the highest bin where the counts exceed relative_cut times the maximum count. If no valid window is found, the histogram is rebuilt with finer bins, up to n_tries times. The output has the unit of min_x.

Keywords

  • n_bins::Int = -1: Number of histogram bins. A negative value selects the Freedman-Diaconis bin width.
  • relative_cut::Float64 = 0.5: Fraction of the maximum bin content that defines the window edges.
  • n_tries::Int = 5: Maximum number of histogram refinements.

Returns

A NamedTuple (low, high, max) with the left bin edge where the counts first reach the cut level on the rising side, the left bin edge where they fall to the cut level on the falling side, and the left edge of the maximum bin.

sipm_simple_calibration(pe_uncal::Vector{<:Real}; kwargs...)
sipm_simple_calibration(pe_uncal_vov::VectorOfVectors{<:Real}; kwargs...)

Determines a linear calibration of SiPM pulse amplitudes to photoelectron (PE) units from the positions of the 1 PE and 2 PE peaks found by a peak finder.

The calibration is pe = c * amplitude + offset, with c the inverse of the distance between the first two peaks and offset chosen such that the first peak lies at min_pe_peak. The noise peak is located with cut_single_peak. The threshold between noise and the 1 PE peak is placed at the center of the first valley after the noise peak; if the valley is too short, at the noise peak maximum plus 3 times its half-width, and if none is found, at the end of the search range. Peaks are searched on a Savitzky-Golay smoothed histogram with RadiationSpectra.determine_calibration_constant_through_peak_ratios; if that fails, local maxima are used. Neighboring peaks closer than 60 % of the largest peak distance are merged.

The method for VectorOfVectors takes the trigger amplitudes of each waveform. It determines the threshold from the finite triggers (of waveforms with at most cut_pool_max_mult triggers if single_trigger_only is true), keeps the triggers above it (only waveforms with exactly one such trigger if single_trigger_only is true), and calibrates these with the vector method.

Keywords

  • initial_min_amp::Real = 0.0, initial_max_amp::Real = 50.0: Amplitude range for the noise peak and peak search.
  • relative_cut_noise_cut::Real = 0.5: Relative cut level of cut_single_peak for the noise peak.
  • n_fwhm_noise_cut::Real = 5.0: Upper limit of the valley search in half-widths of the noise peak above its center. 0.0 skips the valley search and uses initial_min_amp as threshold. A negative value places the threshold at the noise peak maximum plus this factor times the noise peak half-width.
  • min_pe_peak::Int = 1, max_pe_peak::Int = 5: First and last PE peak considered (vector method).
  • initial_max_bin_width_quantile::Real = 0.9: Quantile of the amplitudes up to which the bin width is determined (vector method).
  • peakfinder_σ::Real = -1.0: Expected peak width in bins; a non-positive value estimates it from the noise peak (must be an integer otherwise).
  • peakfinder_threshold::Real = 10.0, peakfinder_rtol::Real = 0.1, peakfinder_α::Real = 0.05: Threshold, relative tolerance and significance level of the peak finder.
  • single_trigger_only::Bool = true, cut_pool_max_mult::Int = 3: Waveform selection (VectorOfVectors method).

Returns

A tuple (result, report). result is a NamedTuple with the fields

  • pe_simple_cal: calibrated amplitudes (vector method).
  • peakpos: peak positions in uncalibrated units.
  • f_simple_calib, f_simple_uncal: the calibration function and its inverse.
  • c, offset: slope and offset of the calibration.
